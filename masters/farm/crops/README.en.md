# Phase 2 Core Crops and Phase 3 Herb / Low Crop

**Language:** [Tiếng Việt](README.vi.md) · English

**Status:** Canonical Phase 2 and Phase 3 growth-stage reference<br>
**Project:** Mayhoa<br>
**Art style:** Mayhoa Nostalgic Hand-Painted Farm Sprite

This folder contains the masters for the 5 growth stages of rice, corn and carrot in Phase 2, plus tonkin-jasmine (Vietnamese: thiên lý), culantro (Vietnamese: ngò gai) and mint in Phase 3. Each crop has growth silhouettes that differ structurally; we do not take one drawing and just scale it up.

## Growth stages

1. `stage-01_seeded`
2. `stage-02_sprout`
3. `stage-03_young`
4. `stage-04_mature`
5. `stage-05_harvestable`

## Phase 2 core crops

- `rice/` — tiny sprout -> expanding grass clump -> mature rice clump -> clearly readable golden panicles at harvest.
- `corn/` — tiny sprout -> broader leaves -> structured stalk -> tassel -> readable corn ears at harvest.
- `carrot/` — tiny sprout -> leafy rosette -> denser feathery foliage -> subtle root shoulder -> orange root cue at harvest.

## Phase 3 herb / low crops

- `tonkin-jasmine/` — thiên lý / Telosma cordata; seeded emergence -> tiny vine sprout -> young leafy vine -> mature vine with heart/ovate-shaped leaves -> restrained pale yellow-green flower clusters at harvest.
- `culantro/` — ngò gai / Eryngium foetidum; emergence -> tiny basal rosette -> widening young rosette -> dense mature rosette -> lush harvestable rosette with long, narrow leaves and clearly suggested serrated edges. Do not use the feathery foliage of coriander/cilantro.
- `mint/` — mint; textured oval-to-lanceolate leaves growing in pairs -> branching stems -> an increasingly dense, lush mint clump, keeping the leaf-edge/texture cues readable at gameplay scale.

## Locked production rules

- transparent 512x512 master canvas;
- crops are bottom-anchored sprites: root `(256, 458)` = `(0.5, 0.89453125)`, pinned by the engine to the soil-plate center (replacing the legacy `(0.5, 0.684)` anchor as of 2026-08-26);
- the asset base aligns to the Phase 1 soil footprint;
- upper-left lighting, soft contact shadow, selective dark-chromatic outlines;
- no baked soil, weeds, pests, UI, text or scene background;
- stage progression must change silhouette, density and focal cues;
- species identity must stay readable at the 192px runtime cell.

## Runtime atlas

`runtime/1x/farm/crops/farm_crops_v01.png` is a 960x1152 shared-texture atlas with 192x192 cells, packing all 6 crop packs (Phase 2 + Phase 3) into one texture: 6 species x 5 stages = 30 frames. `runtime/farm_crops_v01.json` holds the frame coordinates, the per-frame anchors and `stageNames`.

- Rows are in alphabetical order: carrot, corn, culantro, mint, rice, tonkin-jasmine. Columns follow `stageOrder` = `stage-01`..`stage-05`.
- The frame key is a **slot id** `<species>_stage-0N` (for example `culantro_stage-04`), carrying no semantic label — the game builds the key straight from species + stage index, with no lookup table. The semantic labels live in `stageNames` (`<species> -> ["seeded","sprout",...]`) and are for display only.
- The anchor is a uniform `(0.5, 0.894531)` across all 30 frames (`anchorUniform: true`), matching the master root `(256, 458)`. `anchor.x` is always = 0.5 because every master is already centered on its canvas — do **not** measure a bottom-band centroid to derive anchorX (that heuristic is wrong for rosette morphology, see spec §7.1).
- `masterCanvas` = 512x512 for the whole atlas.

This atlas replaces `core_crops_v01` + `herb_crops_v01` (both deleted from the repo). An atlas is a **product generated from the masters, never hand-edited** — rebuild it with:

```bash
python3 tools/build_atlas.py --atlas farm_crops_v01   # add --dry-run to preview
```

Run `python3 tools/build_atlas.py` with no arguments to rebuild all 4 atlases (`farm_crops_v01`, `farm_trees_v01`, `farm_aquatic_v01`, `farm_soil_v01`). The script is idempotent: two runs produce byte-identical output.

## Artwork and production pipeline

Phase 2 once used a deterministic Pillow workflow. That detail is kept only as historical provenance for Phase 2 and is not an authoring rule for Phase 3 or for any asset pack painted/generated later.

Phase 3 source art is bitmap artwork actually painted/generated by the built-in imagegen system. Pillow, sips, ImageMagick and similar raster tools are permitted only for non-art-authoring production work, such as proportional downsampling, atlas packing, metadata/alpha inspection, contact sheets and QC. They must not be used to paint, synthesize, add or reshape plant artwork.

## Acceptance criteria

Each pack is locked when all 15 frames: (1) are clearly distinguishable at gameplay size, (2) sit plausibly on the shared farm footprint, (3) preserve coherent progression and relative scale across crops, and (4) read as more clearly harvestable without going glossy or neon.
